# على الخط · On the Line

تطبيق لتمرين الإنجليزي لشغل الكول سنتر والإنترفيو. بيشتغل في المتصفح من غير ما تنزّل حاجة.

- **كلمات وتعبيرات**: بتراجعها بالمراجعة المتباعدة، والكلمة اللي بتنساها بترجعلك بدري.
- **الأصوات**: P/B وTH وF/V، والمايك بيقولك نطقت صح ولا لأ. المايك بيشتغل في Chrome.
- **جرامر**: بتصلّح الجمل اللي فيها الأغلاط المشهورة.
- **مكالمات وإنترفيو HR**: محتاجين مفتاح Gemini مجاني من https://aistudio.google.com/apikey

تقدّمك ومفتاحك محفوظين في المتصفح بتاعك بس.
